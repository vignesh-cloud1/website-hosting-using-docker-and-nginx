# Website Hosting Using Docker and Nginx

This project demonstrates hosting a static website using Docker containers and the Nginx web server.

## Technologies Used
- Docker
- Nginx
- Linux

## Tasks Performed
- Installed Docker
- Pulled Nginx image
- Created Docker container
- Hosted static website using Nginx
- Verified website accessibility

## Learning Outcome
Learned the basics of containerization, web hosting, and Docker container management using Nginx.
